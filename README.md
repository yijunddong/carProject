# 자동차 검사 관리 시스템

## 프로젝트 소개
자동차 검사장의 접수실, 검사실, 대기실 관리를 위한 웹 기반 시스템입니다.

## 주요 기능
1. 접수실
   - 신규 차량 접수
   - 차량 정보 수정/삭제
   - 대기 차량 목록 관리
   - 완료 차량 목록 확인

2. 판정실
   - 검사 대기 차량 목록 확인
   - 차량 호출 기능
   - 검사 완료 처리
   - 완료 차량 목록 관리

3. 대기실
   - 실시간 대기 현황 표시
   - 검사 완료 알림
   - 자동 화면 갱신
   - 슬라이드쇼 배경 이미지

## 기술 스택
- Frontend
  - HTML5
  - CSS3
  - JavaScript (ES6+)
  - jQuery
  - Bootstrap 4.6.2
  - Font Awesome 5.15.4

- 실시간 통신
  - WebSocket
